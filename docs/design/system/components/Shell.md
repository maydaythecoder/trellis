# Shell

The page chrome, identical at every zoom level: Trail across the top, the collapsed-sibling rail down the left (titles written vertically, the open one in `signal`), the stage in the middle on the dot-grid `ground`, and the status bar along the bottom with the live keycaps on the left and context (model, spend, time) on the right. Only the stage changes when you burrow.

Consumer provides: `trail` and `onGo`, `rail` entries, `status` content, and the stage as children — Panels tiled at `space-6`. The preview here is a showcase page, not a bundle export: it shows one burrow, Overview → agent → file → diff, as three stages side by side. In the terminal the Shell is the same four regions in rows and columns (Trail row 1, status bar last row, rail 3 columns wide).

# Ascii

Preformatted mono art on `panel-inset` with the friendly radius: a face (`blank`, `happy`, `side`, `cheer`, `shrug`, `sleep`) or any multi-line art as children — a box-drawn frame, a tree, a tiny diagram, a logo made of characters. `tone="play"` sets it in lime, `signal` in amber, `muted` recedes. `caption` adds one `meta` line beneath.

Consumer provides: a `face` or the art, a `label` describing it for screen readers, and the caption. This is the register dial: a serious screen uses Ascii for box frames and trees and no faces; a playful one gets one face per screen, placed where a person would otherwise see nothing (an empty state, a finished job, a loader). Never more than one face on a screen, never emoji.

# RunView

The Run view, whole: a page that composes NowStrip, Agents, Budget, Plan, Transcript, Queue and Code on one overview and burrows from it. It is a showcase, not a bundle export, and it answers six complaints about the current desktop in one place: what is running (NowStrip, Agent states, the live dot); what is queued (Queue, with reorder/edit/cancel); who did what (typed Transcript entries, you on amber blocks, the agent in plain text, tools as sentences); whether it is readable (sentences, folds, no ids or exit codes outside the expanded raw view); whether you are in control (Budget limits editable and extendable, Plan steps and reasoning editable and sent as steers, Pause/Stop, Apply/Reject, Comment to agent); and whether you can see the code (Code panel on the overview, a full Diff / whole-file level one burrow in, never removed — only folded).

Three levels, no tabs: **Run** (the overview), **Code** (one file: diff or whole file, Apply `A` / Reject `R` / Comment `C`), **Summary** (the path replayed: outcome text, turns, your steers with their text, files, context over the run, models and spend). `⏎`/`→` go in, `ESC` comes out, the Trail shows where you are. The dashed lime "wire" control at the top right is for reviewing the wireframe — it switches state and level — and is not part of the product. Consumers build the real view from the same components, fed by the event stream in **Events to marks**.

# The v1.0 gate, run — 2026-09-20

`ROADMAP.md` fixes five conditions plus one, "no substitutions". This is the
result of running every one of them today, on the benchmark corpus, rather
than reasoning about them.

**Two conditions met outright, one met with a scripted model, one mechanically
met and awaiting a human, and two not met.** The two that are not met are the
two that no amount of code closes.

## 1 — Recall: 72.0% against a threshold of 85%

Both audited samples were re-scored with the resolver's verdicts **regenerated
from current code**, against the committed human judgements. Scoring the stored
pair would replay history, which is how the seed-20260919 file went stale at
47.8% while every document said 67.9%.

```
seed 20260919   RECALL 67.9%  (108/159)   precision 100%
seed 20260920   RECALL 72.0%  (72/100)    precision 100%
wrongly excluded as external   0
```

72.0%, 95% CI [63.2%, 80.8%]. The threshold is 85%. **The interval does not
reach it and the condition fails.**

It sits in the S1 fallback band — at or above the 60% pivot trigger, below the
85% gate — which requires a further backstop before v1.0 can claim the
blast-radius guarantee. Both candidate backstops have been measured and
neither is worth building (fixtures: already closed, 10 sites; return-type
propagation: 67 sites, 0.4pp, against a rule that can only add unsound edges).

## 2 — Unsound edges: none mechanically, and a human still has to look

Three checks, over every `Resolved` edge rather than a sample:

```
target definition exists          structural — an edge holds a SymbolId
name matches after aliasing       5,908 / 5,908, 0 violations
an import path connects the two   0 disconnected, 0 ambiguous
                                  (4,157 connected, 34 via verified inheritance)
```

1,717 same-file + 4,157 + 34 = 5,908, which reconciles exactly against the
recorded `Resolved` count.

**Mechanical verification is necessary and not sufficient.** An edge can name
the right symbol, in a file the caller genuinely imports, and still be the
wrong target. `0 ambiguous` means this corpus left no residue for a human to
adjudicate; it does not mean a human audit is unnecessary. A-34 stands and the
condition is not called.

## 3 — A real change, end to end, with a scripted model

Fresh extraction of poetry 2.5.0, `git init`, defect injected:
`boolean_validator` annotated `-> str` while returning a bool. mypy sees it.

```
   1. BlastRadius { symbol: "boolean_validator" }
   2. RunChecks { ... } check FAILED
   3. ReadFile { path: "src/poetry/config/config.py" }
   4. Edit { old: "-> str:", new: "-> bool:" }
   5. RunChecks { ... } check passed

CONVERGED after 5 iterations, 1 checks passed.
coverage: 22 call sites in the 1 file bound to nothing
          (MethodDispatchUntyped 20, DynamicAttribute 1, and 1 more)
Changes are left in the working tree for you to review. Nothing is committed.
```

Then human approval through the session, which recorded the gap in the commit:

```
fix: boolean_validator returns bool

Coverage at approval: 22 call sites in the 1 file bound to nothing
(MethodDispatchUntyped 20, DynamicAttribute 1, and 1 more).
Unresolved calls are edges the graph could not follow, not defects.
```

Only the source file and the trail were committed; the index cache was
correctly ignored.

**Why this is partial:** the model was scripted. Every part of the harness is
real — real files, real checks, real rollback, real approval — but judgement
was not. This condition is met the moment the plus-row is, and not before.

### A fixture error worth recording

The first attempt committed `.trellis/index.bin`. That was **not** a TRELLIS
defect: the fixture had been copied from a directory where an index already
existed, so the blob was committed before TRELLIS ever ran there to write the
ignore, and a tracked file cannot be un-ignored. Verified by untracking it,
after which `git check-ignore` reports it ignored. The fixture was rebuilt
from the tarball and the run above is the clean one.

Recorded because the diagnosis could have gone the other way, and "the tool
committed a binary cache" is exactly the sort of thing that gets written down
wrongly once and repeated.

## + — A local model at or above the floor

## What stands between here and v1.0

Neither remaining item is code:

1. **A third independent human audit** (A-34, Q-15). The packet is ready to
   produce and the pipeline is validated end to end — two commands, no
   network. It must report *wrongly excluded* as well as recall, because
   ADR 0015 lets a site leave the denominator on the strength of an
   annotation and no automated check can see a wrong exclusion (S21).
2. **A model that can do the work**, which closes conditions 3 and the
   plus-row together. Or the 85% backstop, which closes condition 1 — and
   both known candidates are measured and rejected, so this one needs a new
   idea rather than more effort.

# The wedge, demonstrated — 2026-09-20

The v0.3 exit criterion: *"a real day-later resumption on the benchmark repo
with no re-explaining."*

A day cannot be faked and was not. What was made honest is the **state**: the
work is committed, the process exits, the index cache and the checker cache are
deleted, and the second session starts with nothing in memory. That is what a
day later actually costs — a cold process against a repository on disk. Run on
**poetry 2.5.0**, the benchmark corpus, not the demo repository.

```

$ git status --porcelain         # clean
```

## What running it found

**`trellis why` could not answer its own question.** The first attempt
reported:

```
named in the task; no file matching `boolean_validator` was changed
```

about a run that had changed exactly the file defining it. The factual section
records **files**; a user asking "why does this look like this" holds a
**symbol**, and matching the symbol against paths finds nothing unless the two
happen to share a name.

This is precisely the failure `03-v0.3-memory.md` names — the trail written
faithfully and useless because the grain is wrong — and it would not have
surfaced from a passing test suite, because every test asserted the behaviour
the code had.

Fixed by resolving the symbol through the index to the file that defines it
before matching. That works retroactively: the mapping is recomputed rather
than recorded, so trails written before the fix answer correctly too.

## Superseded in one respect, the same day

This transcript predates the governance convergence gate. `default_kinds` was
`["typecheck"]`, so no governance audit ran in either session — visible above in
`checks: Typecheck- Typecheck+`, and in session one's "1 checks passed".

`Step::Done` now audits the repository's rules before converging. Re-run today,
both sessions would report one more passing check and the trail would record a
`Governance` turn. The fixture's rule is `deny-write`, which is enforced at the
write path rather than by the audit, so nothing about the outcome changes — but
the counts above are the pre-gate ones and are left as they were rather than
edited to match code that did not run.
